# Java Practice Programs

A collection of basic Java programs for learning and practice.

## Programs
1. Swap two numbers
2. Check even or odd
3. Check palindrome
4. Method overloading calculator
5. Find array length
6. Stack using linked list
7. Queue using linked list
8. Singly linked list
9. Factorial
10. Student grade

These programs are intentionally kept simple and beginner-friendly.
